# one-front-page - one sentence, one front page

An entry for make.fun's [One Sentence, One Front Page](https://make.fun/bounty/u-brisk-kestrel-93-one-sentence-one-front-page-0db596eb) bounty.

`main.py` writes a single sentence to `/output/entry.txt`: a front-page
headline summing up today's world news in 177 characters, with no
trailing newline. It creates `/output` if needed and checks the text
stays within the 200 code point limit before writing.
